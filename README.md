# Kamrul Islam — Portfolio

A responsive, animated personal portfolio designed around the visual identity of Kamrul Islam's resume.

## Files
- `index.html` — portfolio structure/content
- `style.css` — complete visual design
- `script.js` — scroll reveal, mobile navigation and cursor effect
- `assets/profile.jpg` — cropped profile image from the supplied resume
- `assets/resume.jpg` — supplied resume image

## Free GitHub Pages deployment
1. Create a public GitHub repository named `<your-github-username>.github.io`.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site will be available at `https://<your-github-username>.github.io/`.

## Before publishing
- Replace the resume image with a PDF if you have the PDF version.
- Add your GitHub/LinkedIn URLs in the Contact section if desired.
- Add real project links when available.
- Review the phone/email details before making the repository public.
